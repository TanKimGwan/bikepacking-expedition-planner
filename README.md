# Bikepacking Expedition Planner

A WebMCP-enabled planner for first-time multi-day bikepackers.

The project turns a simple trip idea into a practical expedition plan with a cycling route, daily stages, distance, elevation, riding-time estimates, and exportable route data. The same planning capabilities are designed to be usable through both the human UI and structured WebMCP tools.

## Hackathon

Built for **The WebMCP Challenge**.

## MVP

- Point-to-point multi-day bikepacking planning
- Start/destination location search
- 2–7 day trip planning
- Road, Gravel, Touring, and MTB bike types
- Road-priority or mixed-surface route intent
- Daily stage breakdown with distance and ascent
- Estimated riding time and feasibility warnings
- Full-route elevation profile
- Metric / Imperial units
- GPX export
- WebMCP tools for location search, trip parameters, plan generation, and plan inspection

## Stack

- Vue 3 + Vite + TypeScript
- Pinia
- Leaflet
- Tailwind CSS + shadcn-vue
- Chart.js
- Zod
- Netlify Functions
- WebMCP
